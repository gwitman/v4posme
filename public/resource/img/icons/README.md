# Íconos PWA - posMe Live

Debes crear los siguientes archivos PNG en esta carpeta:

## Íconos requeridos:

| Archivo              | Tamaño    | Uso                                       |
|---------------------|-----------|-------------------------------------------|
| icon-72.png         | 72x72     | Android antiguos                          |
| icon-96.png         | 96x96     | Android favicon                           |
| icon-128.png        | 128x128   | Chrome Web Store                          |
| icon-144.png        | 144x144   | Windows tiles / iOS splash                |
| icon-152.png        | 152x152   | iPad (iOS)                                |
| icon-167.png        | 167x167   | iPad Pro (iOS)                            |
| icon-180.png        | 180x180   | iPhone Retina (iOS apple-touch-icon)      |
| icon-192.png        | 192x192   | Android principal / Chrome                |
| icon-384.png        | 384x384   | Android splash screen                     |
| icon-512.png        | 512x512   | Android splash / PWA requerido            |
| icon-maskable.png   | 512x512   | Android adaptive icon (con safe zone)     |

## Recomendaciones:

1. Usar tu logo sobre fondo transparente para los íconos normales
2. Para `icon-maskable.png`: centrar el logo en el 80% interior (safe zone), con fondo de color sólido (ej: #1e88e5)
3. Formato PNG con fondo transparente (excepto maskable)
4. Puedes generarlos desde una imagen de 512x512 usando:
   - https://www.pwabuilder.com/imageGenerator
   - https://realfavicongenerator.net
   - https://maskable.app/editor (para el maskable)
